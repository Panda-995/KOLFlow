# v1.4.9 发布测试计划

环境为独立测试数据库、本地生产构建，桌面 1440×1000 与手机 390×844。每个测试使用新注册账号，保留截图，失败时保存 trace、视频和日志。

- P0 / PRODUCTS-01：创建费用+产品商单，填写费用、两件产品及小数估值，保存后编辑、移除再添加产品并完成。断言类型、费用、两件产品与稳定标识、独立账单和逐件资产；截图表单和完成后的商单。
- P0 / IMAGES-01：打开生成的产品资产，批量上传两张 PNG，切换预览、删除封面并刷新。断言图片计数、自动压缩、封面变化与持久化；截图多图预览，检查移动端无横向溢出。
- P1 / TEMPLATES-01：创建费用+多产品模板，一键创建商单再编辑。断言两件产品、费用与独立的新商单。
- P1 / ABOUT-01：进入关于项目，断言显示 package.json 版本；检查页面无未捕获脚本错误。
- P0 / DATA-01：接口回归覆盖旧单产品、旧单图、v2/v3/v4 备份和新版完整备份恢复；检查资产ID、产品标识、图片及账单不丢失、不重复。
- P1 / DATA-02：接口回归覆盖出售/结算历史、状态回退、产品重排、账号隔离、非法数据拒绝与失败导入不破坏当前数据。
- P0 / UPGRADE-01：双架构原生容器使用 v1.4.8 数据目录升级，逐表比对旧字段与全部历史值，核对仅新增可空字段；检查数据库完整性、原目录、自定义复制目录及重启持久化。
- P0 / RELEASE-01：主分支 CI、amd64/arm64 镜像与清单、Android APK包名/版本/签名、双架构 UPK、素材ZIP与校验文件全部核对后公开 Release。
