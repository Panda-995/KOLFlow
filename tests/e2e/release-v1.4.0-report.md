## 发现与修复

- E2E 首轮发现登录页文字标签未通过 `htmlFor/id` 关联输入框，已修复，读屏器和自动化均可按标签识别。
- 响应式通知中心在桌面和移动 DOM 中保留相同文案，测试已限定可见桌面通知，不影响用户功能。
- 最终运行无未处理页面异常；失败证据策略已配置为自动保留截图、视频与 trace。
